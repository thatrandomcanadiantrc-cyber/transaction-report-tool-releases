# Transaction Report Tool — Releases

Official release distribution for the Transaction Report Tool, a desktop
application for generating Excel reports from payment transaction exports.

## Downloads

All releases are published on the [Releases](../../releases) page.

- **Updating an existing install** — the app checks for updates
  automatically. You can also download the update file from the latest
  release and apply it from within the app (About → Apply update from file).
- **New install** — download the installer from the latest release and
  follow the included install guide.

## Update signing

Updates are signed with an Ed25519 key. The application verifies every
update against the publisher's key before installing it.

Signing key ID: `a5a55181d63bf43a`
